## 什么是 TouchFish Cloud？

TouchFish Cloud 是一个**轻量级的在线网站托管服务**，专为快速部署静态网站和简单动态应用而设计。

**核心特点：**

1. **即开即用**：创建项目后立即可用
2. **在线编辑器**：内置代码编辑器，支持多种语言的语法高亮
3. **实时预览**：修改代码后立即生效，打开新标签页就能看到效果
4. **支持 PHP**：不只是静态文件，还能运行 PHP 脚本
5. **文件夹上传**：支持拖拽上传整个项目
6. **零配置**：不需要配置构建工具、部署脚本，上传即可访问

## 为什么需要 TouchFish Cloud？

**传统 GitHub Pages：**
1. 创建 GitHub 仓库
2. Push 代码
3. 在仓库设置里开启 GitHub Pages
4. 等待部署（可能需要几分钟）
5. 发送链接

**TouchFish Cloud：**
1. 拖拽 HTML 文件到上传区
2. 复制链接
3. 完成！

相较于同类的[咯咕云](https://page.xo.je)，TouchFish Cloud：
 - 支持 PHP（可运行简单后端逻辑）（无法跨域读写非当前项目的文件）
 - 支持在线编辑和预览
 - 更丰富的编辑功能
 - 更友好的用户界面
 - 更好的文件上传体验
 - 移动端支持
 - 内置模板
 - Web 访问密码等独有功能

## 功能详解

### 1. 项目管理

TouchFish Cloud 采用**项目制**管理：

- 每个项目有一个唯一的目录名，如 `myproject`
- 访问地址为 `https://icc.gt.tc/myproject/`
- 每个项目有独立的密码保护，只有你能管理

**创建项目：**
```text
项目名：mysite
密码：****
确认密码：****
```

点击“创建项目”，几秒后你就拥有了一个独立的托管空间！

### 2. 文件上传

TouchFish Cloud 支持多种上传方式：

#### 方式一：拖拽上传

直接将文件或文件夹从你的电脑上拖到上传区域：

拖进去，上传完成！整个文件夹结构会被完整保留。

![图片](https://icc.gt.tc/test/image2.png)

#### 方式二：点击上传

点击“选择文件”或“选择文件夹”按钮，选择要上传的内容。

![图片](https://icc.gt.tc/test/image3.png)

#### 方式三：在线创建

在侧边栏点击“新建文件”按钮，直接在线创建新文件：
- 输入文件名（如 `index.html`）
- 开始编辑
- 保存即可（使用保存按钮或快捷键 `Ctrl+S`）

### 3. 在线编辑器

TouchFish Cloud 内置了**基于 CodeMirror 的代码编辑器**，支持：

- **语法高亮**：HTML、CSS、JavaScript、PHP、Python、Markdown 等数十种语言
- **代码缩进**：自动格式化
- **行号显示**：方便定位代码

例如，在你的项目里写入 `index.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>Hello, TouchFish Cloud!</h1>
    <p>这是我在线编辑的网页。</p>
</body>
</html>
```

![图片](https://icc.gt.tc/test/image4.png)

保存后，立即访问 `https://icc.gt.tc/项目地址/` 就能看到效果！

### 4. 多种预览模式

不同类型的文件有不同的查看方式：

#### 文本文件
- HTML、CSS、JS、PHP、Markdown 等：**代码编辑器**
- 语法高亮，可编辑

#### 图片文件
- PNG、JPG、GIF、SVG 等：**图片预览器**
- 自动居中显示，支持缩放

#### 媒体文件
- MP3、MP4、WebM 等：**内置播放器**
- 在线播放音频和视频

#### PDF 文件
- **PDF 阅读器**
- 直接在浏览器中查看

#### 其他文件
- 提供下载按钮

### 5. 文件管理

侧边栏的文件树提供了完整的文件管理功能：

#### 文件搜索
在顶部搜索框输入文件名，快速定位文件。

#### 新建文件/文件夹
点击上方的“新建文件”或“新建文件夹”按钮以创建新的文件或文件夹。

![图片](https://icc.gt.tc/test/image4.png)

#### 右键菜单
在文件上右键，可以：
- **打开**：在编辑器中打开
- **重命名**：修改文件名
- **下载**：下载到本地
- **删除**：删除文件（谨慎操作！）

### 6. 多标签系统

像浏览器一样，编辑器支持**多标签**切换：

可以同时打开多个文件，快速切换编辑。


### 7. PHP 支持：不止于静态

与大多数静态托管服务不同，TouchFish Cloud **支持 PHP**！

你可以：
- 创建动态网页
- 实现简单的后端逻辑

例如，在你的项目里创建一个 `index.php`（先删除 `index.html`）：

```php
<?php
echo "Hello, TouchFish Cloud!";
?>
```

访问 `https://icc.gt.tc/项目地址/` 就能直接看到输出结果！

PHP 只能访问当前项目内的文件，无法跨项目读写，也无法访问服务器上的其他资源。

大部分非必需文件函数和远程文件读取都无法在 PHP 中使用。

### 8. 存储配额

每个项目默认提供 **100MB** 的存储空间，足够托管大多数静态网站和小型动态应用。

较大的文件上传可能无法成功（即使未超出存储配额），请注意文件大小，如上传时出现“未登录”提示，请检查文件大小并确认当前会话已登录。

如有需要，可以向 `ilovescratch@foxmail.com` 发送邮件，申请增加存储配额。申请时请提供项目名称、需要的配额大小、申请理由（如用途、项目类型等）。

### 9. 模板

不同于其他服务，TouchFish Cloud 提供了模板功能，可以从模板创建，更加方便快捷！

可使用编辑器左侧的“从模板创建”按钮重新创建项目。

#### 示例：

模板：文件查看器
![图片](https://icc.gt.tc/test/image6.png)

模板：简约博客
![图片](https://icc.gt.tc/test/image7.png)

将会加入更多模板，使得网站上线更加简单！

### 10. 访问保护、只读访问

在编辑器右上角，有“项目设置”选项，可以删除项目，设置部分高级功能，如 Web 访问密码，只读访问密码等！

![图片](https://icc.gt.tc/test/image11.png)


做了一个项目，但是只想给好友发，不想让别人访问？
TouchFish Cloud 支持设置“Web 访问密码”来保护项目！

![图片](https://icc.gt.tc/test/image8.png)

想分享项目文件？可设置“只读访问密码”，使用只读密码可以进入项目，但是无法进行任何编辑操作！

![图片](https://icc.gt.tc/test/image9.png)


## 注意：

- TouchFish Cloud 目前仅支持静态文件和 PHP 脚本，不支持复杂后端功能
- TouchFish Cloud 仅用于合法目的，不得用于非法活动
- 单 IP 创建项目的数量有限制，以避免滥用，编辑项目没有数量限制
- 违反使用条款的项目会被删除
- 违反使用条款的 IP 会被封禁

可以向 `ilovescratch@foxmail.com` 发送邮件举报违反使用条款的项目。
